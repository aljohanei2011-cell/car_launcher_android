# رفيق الطريق الجديد — لانشر مستقل

لانشر منفصل تماماً عن تطبيق «رفيق الطريق» القديم (`app/`): مشروع مستقل، ومعرّف تطبيق مختلف (`com.aljohanei.rafiq`)، فيُثبَّت بجانب القديم دون أن يغيّره.

- واجهات أندرويد الأصلية فقط، بدون WebView وبدون مكتبات خارجية، ليعمل بخفة على شاشة بذاكرة 2 جيجا.
- تصميم ثابت 1280×720 يُكبَّر أو يُصغَّر ليملأ الشاشة.
- البطاقات: الوقت والتاريخ الهجري، الطقس، كمبيوتر الرحلة، المباريات (السعودي والأوروبي)، الموسيقى، الصلاة والقبلة، الأذكار، الملاحة.
- عداد بثلاثة أشكال (قوس، حلقة، شريط) حتى 200 أو 240 كم/س، ومنطقة خطر ظاهرة، وتنبيه سرعة.
- أيقونات البلوتوث والموقع والواي فاي، وزر «إغلاق الكل» لتحرير الذاكرة.
- قائمة سفلية بست خانات؛ الضغط المطوّل على الملاحة أو الموسيقى أو التطبيقات أو معلومات السيارة يضع مكانها أي تطبيق.
- ثيم تلقائي حسب الشروق والغروب، وخفض السطوع ليلاً.
- تنبيهات الصلاة بمنبّه واحد للصلاة القادمة (أم القرى، محسوبة محلياً).

## البناء

يبنيه `.github/workflows/build-rafiq-native.yml` عند الدفع إلى فرع `rafiq-native`، وينشر الملف في الإصدار التجريبي الثابت `rafiq-native` باسم `rafiq-native.apk`. هذا الإصدار لا يراه محدّث التطبيق القديم.

```
gradle -p rafiq_native :app:assembleRelease
```
