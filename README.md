# رفيق الطريق — لانشر أندرويد للسيارة

لانشر أندرويد (Android 9 إلى 11) يعمل بدون إنترنت، ويعرض:
- الساعة والتاريخ الميلادي والهجري
- مواقيت الصلاة محسوبة على الجهاز (الظهران أو الرياض)
- مؤقت الصلاة الدائري
- شاشة الاستراحة مع أدعية متغيرة
- الأذكار (صباح، مساء، سفر)
- عداد الرحلة من GPS (مع بيانات تجريبية عند عدم توفره)
- الإعدادات: الخلفية، الخط، المدينة، والبطاقات المصمتة

## البناء
1. افتح المجلد في Android Studio.
2. انتظر حتى ينتهي Gradle Sync.
3. Build ▸ Build APK.

## ملاحظات
- الشعار: الخانة فارغة (`[ضع شعارك هنا]`)، ويُضاف لاحقاً.
- الخط: ثمنية سانس، والترخيص على مالك المشروع التحقق منه قبل النشر.
- الحد الأدنى: Android 9 (API 28). الهدف: Android 11 (API 30).
