# رفيق الطريق 3.0 — واجهة سيارة عربية لأندرويد

تطوير: **عاصم الجهني**

واجهة (لانشر) لشاشات السيارات بنظام أندرويد، عربية بالكامل، وتعمل بدون إنترنت. صُممت لشاشات السيارات الشائعة (1024×600 و1280×720 و1920×1080) وتتمدد للشاشات العريضة.

## التحميل

| النسخة | لمن | الرابط المباشر |
|---|---|---|
| الكاملة | الشاشات المتوسطة والقوية | [rafiq.apk](https://github.com/aljohanei2011-cell/car_launcher_android/releases/latest/download/rafiq.apk) |
| الخفيفة | الشاشات الضعيفة (ذاكرة 2 جيجا أو أقل) | [rafiq-lite.apk](https://github.com/aljohanei2011-cell/car_launcher_android/releases/latest/download/rafiq-lite.apk) |

- يعمل على أندرويد 9 فما فوق، ويحتاج «Android System WebView» إصدار 80 أو أحدث.
- بعد التثبيت الأول يتحدّث التطبيق من الشاشة نفسها: الإعدادات ▸ تحديث التطبيق.
- النسختان نفس التطبيق: التحويل بينهما من صفحة التحديث، وتبقى الإعدادات والبيانات.

## قنوات التحديث

- **ثابتة** (الافتراضية): يصلها الإصدار الكبير بعد يومين من نشره، وإصدار «الإصلاح العاجل» فوراً.
- **تجريبية**: يصلها كل إصدار فوراً. اختر شاشة واحدة للتجربة قبل البقية.

## أهم المزايا

- **الرئيسية**: بطاقات قابلة للتحرير بالضغط المطوّل (حجم النص، ما يظهر، المكان، النوع، القفل)، وأربعة تصاميم، وتخطيطات محفوظة.
- **الصلاة**: مواقيت أم القرى محسوبة على الجهاز، وتنبيهات تعمل والخرائط مفتوحة، والقبلة، وتذكير الجمعة، ووضع رمضان، وتنبيه المواقيت للحج والعمرة.
- **المظهر**: ستة ثيمات (منها السعودي وأوقات الصلاة)، وتأثيرات الطقس، وسبعة أشكال للساعة، وخطوط تضيفها من جوالك.
- **القيادة**: السرعة والرحلات، وتنبيه النعاس، وأقرب مسجد ومحطة وصراف، ومخطط رحلة السفر، وتكلفة الوقود، والشاشة المبسطة عند السرعة.
- **التنبيهات والمباريات**: تنبيهات زجاجية بمكان تختاره (وفوق الخرائط)، وتأجيل التذكير، وبطاقة المباريات مع تنبيهات الأهداف (بيانات ESPN العامة).
- **الأوامر الصوتية** (اختيارية): ملاحظات وتذكيرات ومصاريف وملاحة وموسيقى بالصوت.
- **السيارة**: الصيانة ووثائق السيارة، والمصاريف، وقارئ OBD بلوتوث (ELM327).
- **الجوال**: إرسال الصور والتطبيقات والخطوط والملاحظات والنسخ الاحتياطية من الجوال بالباركود (شبكة محلية فقط).
- **الأمان**: وضع الضيف، والرقم السري، ووضع الأمان عند تعطل الواجهة، ونسخ احتياطية تلقائية داخل الشاشة.

## الأذونات ولماذا

| الإذن | السبب |
|---|---|
| الموقع | مواقيت الصلاة بموقعك، الرحلة، السرعة، القبلة |
| الوصول إلى الإشعارات | عرض الموسيقى والتحكم بها، واسم المتصل (لا يُقرأ نص أي رسالة) |
| تعديل إعدادات النظام | خفض السطوع ليلاً (اختياري) |
| الظهور فوق التطبيقات | إعادة فتح الواجهة إن أغلقها النظام (اختياري) |
| تثبيت التطبيقات | التحديث من الشاشة والتطبيقات المرسلة من الجوال |
| الميكروفون | الأوامر الصوتية فقط، وعند تفعيلها |
| البلوتوث | حالة البلوتوث وقطعة OBD |

## الخصوصية

كل البيانات على الشاشة فقط. التطبيق لا يجمع أي بيانات ولا يرسلها لأي جهة. الإنترنت يُستخدم للطقس (Open-Meteo) والتحديثات (GitHub) فقط.

## التراخيص

- خط «ثمانية سانس» وخط «اليمامة»: رخصة SIL Open Font License.
- صور الثيمات مولّدة خصيصاً للتطبيق.
- أسماء ماركات السيارات تظهر نصاً فقط دون شعارات، وهي ملك أصحابها.

## للمطور

- البناء تلقائي عبر GitHub Actions مع كل دفع إلى `main`: نسختان `full` و`lite` (Gradle product flavors) موقّعتان بنفس المفتاح.
- الواجهة صفحات HTML داخل `app/src/main/assets`، وصور الثيمات في `app/src/full/assets` (لا تدخل النسخة الخفيفة).
